## 2. Orphan & Duplicated State Findings (Sections 6 & 7 Pre-Audit)

1. **`avast_tray` Orphan in `startupApps` (`js/apps/settings/apps.js:38`)**: Uninstalling `avast_antivirus` removes it from `installedPrograms`, but leaves `{ id: 'avast_tray', name: 'AVAST! Tray Shield' }` behind in `startupApps`.
2. **Hardcoded Default PDF Viewer (`js/apps/settings/apps.js:65`)**: `Default apps` subpage renders `Adobe Reader 9.3` as a static string even when `adobe_reader` is uninstalled.
3. **Search App Catalog Out-of-Sync (`js/core/search.js:24-33`, `js/registry/settings-registry.js:230`)**: `Search` returns `Apps -> Installed apps` on keyword `"avast"`, and doesn't list/prune uninstalled desktop apps live from `installedPrograms` or `userApps`.
4. **Hardcoded `12:00` Lock Screen Preview Time (`js/apps/settings/personalization.js:143`)**: Ignores `Win11State.getSimulatedNow()` and selected Timezone.
5. **Settings Home Wrong Value Badge (`js/apps/settings/home.js:67`)**: `Language & region` card displays `st.timeZoneId` (`GMT+0`) instead of Language metadata.
6. **Taskbar Language Desynchronization (`js/core/taskbar.js:207,277`)**: Displays UI `displayLanguage` while Settings manages `installedLanguages` (`1` entry by default).
7. **Quick Settings Bluetooth vs Airplane State Desync (`js/core/quick-settings.js:223` vs `js/apps/settings/devices.js:96`)**: Clicking Bluetooth tile in Quick Settings left `airplaneMode: true` intact while mutating `bluetoothEnabled` unseen.
8. **File Explorer Duplicated Static Folder Cards (`js/apps/file-explorer.js:107-114`)**: Every user folder showed identical hardcoded cards regardless of folder (`Documents` vs `Downloads` vs `Desktop`).

## 4. UNCERTAIN Rows Requiring Human Verification

Per Section 0 rules, the following items are NOT silently guessed and remain flagged for teacher/human confirmation:

1. **Taskbar Tray Short Date Format under Arabic (`ar-DZ`) Windows 11**: Whether your school lab machines display `DD/MM/YYYY` (`11/11/2026`) or `YYYY/MM/DD` (`2026/11/11`) in the Windows 11 Arabic (Algeria) taskbar tray (`YYYY/MM/DD` is currently shown cleanly in `formatClockDate`).
